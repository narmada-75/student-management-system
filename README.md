Student Management System

Overview

The Student Management System is a Python-based application that uses MySQL to store and manage student records. It provides a simple menu-driven interface for performing CRUD (Create, Read, Update, Delete) operations.

Features

- Add Student
- View All Students
- Search Student by Roll Number
- Update Student Details
- Delete Student Records
- Menu-driven interface

Technologies Used

- Python 3
- MySQL
- MySQL Connector for Python
- Visual Studio Code (VS Code)

Database

Database Name: "student_db"

Table Name: "students"

Project Structure

Student-Management-System/
│── student_management.py
│── README.md
│── requirements.txt
└── screenshots/

Installation

1. Install Python.
2. Install MySQL Server.
3. Install the MySQL Connector:

pip install mysql-connector-python

4. Create the "student_db" database and the "students" table.
5. Run the project:

python student_management.py

Learning Outcomes

- Python Programming
- MySQL Database Operations
- CRUD Operations
- Database Connectivity using mysql-connector-python
- Basic Error Handling
